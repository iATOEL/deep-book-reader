# 数的写法：从记号到位值

## 第 1 章 从"数出来"到"写下来"

计数与记数是两种不同的活动。计数是在当下对一组物逐个点名，它的产物是一次短暂的动作，随着点名结束而消失。记数则要求把这次点名的结果固定在一个不依赖在场者身体的外部载体上。因此，记数系统的第一个内在要求不是精确，而是可复现：即使点名者不在场，另一个人也能从载体上读出同一个数量。

可复现的要求把记号从"动作的痕迹"变成"约定的对象"。只有当一群使用者共同承认某个刻痕代表某个数量时，刻痕才成为记号；否则它只是一个刻痕。

早期记号采取一一对映策略：每个被计数的单位都在载体上留下一个独立符号，例如刻痕、绳结或石子。这一策略满足可复现性，却把记数的成本直接绑在数量上——数量翻倍，符号数量也翻倍。要摆脱这种绑定，记号系统必须做到两件事：让符号的种类而不是数量承担区分功能，让符号在载体上的位置参与意义的构成。前者产生基数符号，后者产生位值的雏形。

于是，当符号种类与位置这两套规则合并之后，抽象的记数系统便取代了刻痕式的记数，计算也随之成为可能。

需要说明的是，位值的雏形可能最早出现在需要处理大额数量的记账场景中，而不是出现在纯粹的数论思考中。

一个可以说明"位置已经开始承担意义"的例子是罗马数字的对读：IX 与 XIII 中的 I 必须结合它出现在 X 前还是 X 后，才能分别读作减一与加一。位置关系已经参与意义构成，但位置本身还没有被赋予固定的权重。

## 第 2 章 位值制的代价

位值制并不是没有代价的。第一条代价是学习成本从数量转移到规则：使用者必须先掌握位与权的对应关系，才能读出任何一个数；而刻痕式记数的使用者只需要逐个辨认符号。前者把成本前置，后者把成本后置。

第二条代价是空位问题。当某个位没有量时，如果什么都不写，该位就会与相邻位混淆，因此系统需要一个可书写的占位符号。占位符号的出现并不是为了表示"什么都没有"，而是为了让位置本身可以被稳定地识别。

位值制的优势也不是无条件的。在不追求计算、只追求一次性记录的场合——例如只在石壁上刻下一个数量——刻痕式记数与位值制在功能上不可区分。只有当同一批数量需要被反复比较、累加与传递时，位值制带来的规则成本才会被运算收益抵消。
