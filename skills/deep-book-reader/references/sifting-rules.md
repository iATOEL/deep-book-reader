# 拆解与筛滤细则

Step 3 的判定规则。所有规则的目标只有一个：**让解释密度最大化，同时不越出原文边界**。

## 1. 概念去重与拆分

### 合并条件

多个小节围绕同一核心理论节点展开，且不存在实质性的逻辑递进、转折、论证关系变化或边界变化时，必须合并为一个板块，仅提炼其共同理论主干。

### 拆分条件

只要出现下列任一项，强制独立成板块：

- 新术语或新概念
- 逻辑递进或逻辑转折
- 新的因果链条
- 新的边界条件、适用范围或例外
- 反驳、异议或思想实验

### 保守原则

- 删去某小节会导致理论链条断裂 → 独立
- 无法确定能否合并 → 优先独立
- 允许合并重复内容，严禁改变原书论证顺序

### 判定流程

```text
取下一小节
  ├─ 引入新术语/概念/因果链/边界/反驳？ ── 是 → 独立板块
  ├─ 与上一板块存在递进或转折？       ── 是 → 独立板块
  ├─ 去掉后链条是否断裂？             ── 是 → 独立板块
  └─ 以上皆否 → 合并进上一板块，仅保留共同理论主干
```

## 2. 解释密度与防概念堆叠

### 拒绝结论罗列

禁止只回答"作者说了什么观点"。每个板块必须在正文中讲透该节点内部的核心概念、原文明确给出的前提、推导机制及其逻辑关系。

### 防高密度概念串联

严禁把多个抽象术语直接堆叠成一句结论输出。凡涉及抽象推导，正文必须展开其转换与作用的具体机制。

### 复杂度阈值

一句话或连续表述同时引入 **3 个及以上彼此依赖**的抽象概念、术语或理论关系时，不得继续压缩为一句总结，必须拆开解释这些概念之间的逻辑连接与演进过程，直到呈现清晰的中间机制。

### 段落级机制展开

一个板块内部包含两个及以上彼此依赖的理论节点或推导转折时，不得压缩为单一高密度段落；应自然分成多个段落，每段承担一个明确的机制解释任务。

### 机制展开骨架（写作时逐项自问）

1. 该概念要解决的问题或前置障碍是什么
2. 原文给出的前提有哪些（逐条列清，不合并）
3. 从前提推出结论的**转换机制**是什么
4. 为什么该机制有效／必要（原文给出的依据）
5. 该结论的边界条件、例外与适用限制
6. 原文是否跳过了上述任一项？跳过即标注 `【原文逻辑跳跃】`

只有完整完成一个板块内部的逻辑解构后，才允许进入下一个板块。

## 3. 例证极简法则

- **精选原则**：每个理论点默认最多保留 1 个最具代表性或反直觉的例证
- **二维例外**：仅当例证分别对应不同维度、适用条件或论证功能时，最多保留 2 个
- **理论节点例外**：例证承担定义、推导、反驳、思想实验或边界条件功能时，视为理论节点完整保留，不受精简规则限制
- **严禁罗列**：禁止把同质化例证以排比句、连续列表或案例清单形式堆砌

判定口诀：**例证变长句清单 → 压缩为一个；例证承担论证功能 → 原样保留。**

## 4. 正文与扩展的分工

| 区域 | 承载内容 |
| --- | --- |
| 讲解正文 | 概念定义、理论拆解、推导机制、论证步骤、关键转折、边界条件、精选例证。所有理论拆解必须且只能在正文中呈现 |
| `> 【扩展补充】` | 仅 1 个日常通俗类比，用于建立直观理解；每章最多 1–2 处，仅附于最抽象的核心概念之后 |

扩展补充的禁止项：外部学术假说、具体人物、历史事件、新结论、任何原文未支持的数据。

无贴切类比时，整个 `> 【扩展补充】` 引用块（含 `>` 符号本身）必须删除，严禁保留空块或写"无"。

## 5. 边界与逻辑防越界

- 不得把外部知识写入正文；不得把自己的推论写成作者明确提出的观点；基于文档的推论必须标注 `【基于文档的推论】`
- 原文未提供某个前提或推导步骤时，只能忠实呈现原文实际给出的逻辑，不得自行修补
- 尽可能保留作者的核心专业术语；首次出现时用通俗语言解释，但不得用自己的概念体系替换作者的术语体系
- 低相关性的书外背景（作者生平、学派评价、成书历史、其他著作对照）一律不得进入正文与附录

### 论证强度保真

| 原文模态 | 允许的写法 | 禁止的写法 |
| --- | --- | --- |
| 可能、也许、或许 | 保留"可能"级强度 | 必然、一定、证明 |
| 倾向于、似乎、暗示 | 保留倾向性表述 | 明确证明、确立 |
| 意味着、表明（有条件） | 保留条件限定 | 无条件断言 |
| 必然、证明、确立（强结论） | 保留强断言 | 弱化为"可能""有待验证" |

## 6. 正反例对照

**A. 概念堆叠**

- 反例：`序数的抽象、基数符号的出现与位值零的引入，三步完成了数的符号化。`
- 正例：分三段分别说明——序数只回答"第几个"却无法独立指称集合规模，因此需要基数符号来把"量"从"次序"中剥离；基数符号解决了种类问题却仍需与数量同增的符号数，因此需要位置参与意义构成；当某个位置空缺时会与相邻位混淆，因此需要占位符把"空位"变成一个可书写的对象。

**B. 结论罗列**

- 反例：`作者认为语言塑造思维，并举了颜色词的例子。`
- 正例：先写明原文给出的前提（颜色词的切分方式在不同语言中不一致），再写明原文的推导链条（若知觉先于语言则应存在跨语言一致的切分），最后写明结论与原文自设的边界条件（该论证仅覆盖可记忆的颜色区间）。

**C. 例证堆砌**

- 反例：`例如 A、例如 B、例如 C，都说明同一结论。`
- 正例：保留其中承担反直觉功能的一个，并说明它为何构成对结论的挑战或支撑。

**D. 模态改写**

- 反例：原文写"位值雏形**可能**最早出现在记账场景"，研读写"位值制**起源于**记账需求"。
- 正例：`原文表述为"可能最早出现在记账场景"（第 1 章 §记账），此处按原强度保留，不做起源断定。`

## 7. 篇幅参照（非硬指标）

- 膨胀比 = 研读文档该章正文字数 ÷ 原文该章正文字数
- 参考区间：理论密度高的章节 1.2–3.0；叙述性强的章节 0.3–0.8 亦属正常
- 膨胀比 < 1.0 而章节本身为高密度理论章节时，通常意味着发生了摘要化，回到该章补足机制展开
- 篇幅由实际逻辑节点与推导复杂度决定，绝不为了压缩而牺牲理论深度，也不为凑长度注水
