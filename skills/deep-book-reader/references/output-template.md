# 输出文档模板与格式契约

本文件是 Step 2 建骨架、Step 3 逐章写入、Step 5 校验的唯一格式依据。`scripts/check_output.py` 按本契约实现检查。

## 1. 文件与命名

- 路径：`<工作目录>/deep-reading/<书名>_深度研读.md`
- 书名清洗：去掉 `\ / : * ? " < > |` 与首尾空格；保留书名号或副标题可读性
- 编码：UTF-8（无 BOM）；换行使用 `\n`
- 中间工作文件（章节切分、断点记录）放在 `deep-reading/_work/`，不属于交付物

## 2. 标题层级契约（脚本按此校验）

| 层级 | 用途 | 数量约束 | 示例 |
| --- | --- | --- | --- |
| `#` | 文档标题 | 全文唯一 | `# 《数的写法》深度研读` |
| `##` | 章 / 全书导读 / 全书总结 / 附录 | ≥ 3 | `## 第 1 章 从"数出来"到"写下来"` |
| `###` | 板块 / 本章总结 | 每章 ≥ 2 | `### 板块 1：记数与计数的分野` |
| `>` 引用块 | 扩展补充（仅类比） | 每章 0–2 | `> 【扩展补充】` |

允许出现的非章节 `##` 标题（白名单，其余 `##` 一律视为章节）：

- `## 全书导读`
- `## 全书宏观总结与底层知识图谱`（限定章节范围时用 `## 范围总结与底层逻辑`）
- `## 附录 X｜<名称>`（A/B/C 三段，X 为单个大写字母）

其他硬性规则：

- 板块编号每章从 1 重新开始，连续递增，不得跳号
- 章节顺序必须与原书顺序一致，不得重排
- 每章有且只有一个 `### 本章总结与深度启示`，且位于该章全部板块之后

## 3. 完整模板

```markdown
# 《书名》深度研读

> **研读范围**：全书（共 N 章）
> **来源文件**：<文件名>（<PDF/TXT/MD>，转为文本后约 N 字）
> **原文规模**：约 N 字 / N 章 / N 节的正文
> **生成时间**：YYYY-MM-DD
> **生成方式**：deep-book-reader skill（<平台> + <模型>）
> **章节划分**：沿用原文既有章节（若原文无章节：研读者依据原文段落结构划分，基于文档的推论）

- 术语：保留作者原术语，首次出现给出通俗解释
```

## 4. 各部分写作规则

### 元信息块

- 位于文档标题之后、第一个 `---` 之前，使用 `>` 引用行
- 必须包含 `研读范围`、`来源文件`、`原文规模`、`生成时间`、`生成方式`
- 原文无章节结构时必须注明章节划分来源并标注 `基于文档的推论`

### 全书导读

- **核心论题**：1–3 句，只能来自原文；不得写成营销式推荐语
- **论证主线骨架**：仅列出原书实际给出的章节级推进；不得补写"作者意图""本书价值"
- **使用约定**：按第 3 节模板原样保留，可按需增删"标注"一行中的条目

### 章标题

- 格式：`## 第 N 章 <原文章节名>`
- 原文章节名过长时保留原题，不擅自缩短
- 原文顺序包含"序章/前言/导论/结语/后记"时，逐一体例化：`## 序章 <标题>`、`## 结语 <标题>`
- 原文无章节标题时：`## 第 N 章 <该部分首句浓缩>`

### 板块

- 标题：`### 板块 N：<核心子主题>`
- 正文承担**一个**清晰的机制解释任务；一个板块中出现两个及以上彼此依赖的理论节点或推导转折时，必须拆成多个自然段，每段一个机制解释任务
- 涉及抽象推导时必须展开转换与作用机制，禁止把 3 个及以上彼此依赖的抽象概念压缩进一句话

### 扩展补充

- 位置：仅紧跟最抽象的核心概念之后
- 数量：每章 0–2 处
- 内容：1 个日常通俗类比；严禁外部学术假说、具体人物、历史事件或新结论
- 无贴切类比：整块连同 `>` 删除，严禁保留空块或写"无"

### 本章总结与深度启示

- 位置：本章全部板块写完之后
- **核心逻辑链条**：`A → B → C` 形式的压缩链条，指向正文已完整推导的内容
- **关键启示 / 复盘**：对正文内容的提炼与再压缩；严禁跳过正文给出未经推导的宏大结论
- 含推论时必须标注 `【基于文档的推论】`

### 全书宏观总结与底层知识图谱

- 仅在最后一章全部讲完时输出；用户限定章节范围时输出 `## 范围总结与底层逻辑`
- 仅整合书中已明确支持的理论与原则；严禁引入书外理论、方法论、案例

## 5. 正文标注约定

| 标注 | 触发条件 | 其他要求 |
| --- | --- | --- |
| `【原文逻辑跳跃】` | 原文从前提直接给出结论，缺少中间依据 | 每次出现都必须在附录 B 汇总 |
| `【基于文档的推论】` | 研读者依据原文作出的推论 | 严禁写成作者明确主张 |
| `【原文位置：第 X 章 §<小节标题>】` | 关键定义、关键结论、弱模态断言处 | 便于溯源，每章建议 ≥ 1 处 |
| `〔原文："……"〕` | 需要逐字呈现的关键定义或弱模态结论 | 引用必须与原文逐字一致，不得改写 |

## 6. 禁止清单

- 占位符：`TODO`、`待补充`、`待完善`、`（略）`、`TBD`
- 截断话术：`受篇幅限制`、`此处省略`、`其余章节脉络类似`、`不再赘述`
- 交互残留：`回复"继续"`、`【第 X / Total 章未完…】`、`当前章节：`
- 结构与内容不符：只有标题没有正文的板块、空引用块、跳号的板块编号
- 书外内容：作者生平、后世评价、其他著作对照、外部学术假说
