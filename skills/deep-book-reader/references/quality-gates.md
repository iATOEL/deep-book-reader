# 交付前自检清单与校验脚本

Step 5 加载。校验分两层：脚本能查的（结构、格式、覆盖率）必须跑脚本；脚本查不了的（忠实度、深度、模态）必须逐条过清单。

## 1. 运行校验脚本

```bash
# 基础校验（结构 + 格式 + 禁止项）
python <skill_dir>/scripts/check_output.py "deep-reading/《书名》_深度研读.md"

# 带覆盖率校验（推荐，需先跑过 split_book.py）
python <skill_dir>/scripts/check_output.py "deep-reading/《书名》_深度研读.md" --manifest deep-reading/_work/manifest.json
```

退出码：`0` 无错误（可含警告）、`1` 存在错误、`2` 参数或文件问题。存在错误时**必须先修正再交付**。

## 2. 脚本自动检查项

| 类别 | 检查内容 | 级别 |
| --- | --- | --- |
| 结构 | `#` 级标题唯一 | 错误 |
| 结构 | 存在 `## 全书导读` | 错误 |
| 结构 | 每个 `##` 章节至少 1 个 `### 板块 N` | 错误 |
| 结构 | 板块编号每章从 1 连续递增 | 错误 |
| 结构 | 每章恰好 1 个 `### 本章总结与深度启示`，且位于全部板块之后 | 错误 |
| 结构 | 存在 `## 全书宏观总结与底层知识图谱` 且位于最后一章之后 | 错误 |
| 结构 | `##` 标题非章节且不在白名单 | 警告 |
| 深度 | 板块正文少于 80 字（疑似结论罗列） | 警告 |
| 格式 | 空 `> 【扩展补充】` 引用块、写了"无" | 错误 |
| 格式 | 扩展补充超过每章 2 处 | 警告 |
| 格式 | 占位符与截断话术（`TODO`、`待补充`、`受篇幅限制` 等） | 错误 |
| 格式 | 交互模式残留（`回复"继续"`、`Total 章` 等） | 错误 |
| 忠实度 | 出现 `【原文逻辑跳跃】` 但缺少忠实度附录 | 错误 |
| 覆盖率 | manifest 中的章节在文档中缺失 | 错误 |
| 覆盖率 | 研读正文 ÷ 原文字数 < 1.0 | 警告 |

## 3. 人工自检清单

### 忠实度

- [ ] 正文所有理论、定义、论证均来自所读原文，无外部知识
- [ ] 原文的逻辑跳跃已标注 `【原文逻辑跳跃】`，未自行补齐
- [ ] 研读者推论已标注 `【基于文档的推论】`，未写成作者主张
- [ ] 弱模态（可能/似乎/倾向于）与强模态（必然/证明）按原文强度保留
- [ ] 作者核心术语未被自造概念替换，首次出现有通俗解释
- [ ] 逐字引用的原文与原文一致，未改写

### 深度与顺序

- [ ] 原书论证顺序未被改动，章节顺序与原文一致
- [ ] 每个板块还原了「前提 → 推导机制 → 结论」链条，解释了 A→B 的依据
- [ ] 无"序数→基数→位值零"式的多概念串联单句结论
- [ ] 一个板块内的多个理论节点已拆成多个自然段
- [ ] 未出现"作者认为……"式结论罗列段落
- [ ] 收尾为完整逻辑板块的自然结束，而非概括式总结

### 去重与例证

- [ ] 同一理论节点的重复表述已合并，未改变论证顺序
- [ ] 每个理论点例证不超过 2 个，且分属不同维度
- [ ] 承担定义/推导/反驳/思想实验/边界功能的例证完整保留
- [ ] 无排比句、案例清单式例证堆砌

### 扩展与附录

- [ ] 扩展补充仅含 1 个通俗类比，无外部假说、人物、历史事件
- [ ] 无贴切类比处已整块删除，未留空块或"无"
- [ ] 附录 A 术语表、附录 B 忠实度清单、附录 C 覆盖率已按模板填写
- [ ] 附录内容不引入书外理论

### 交付

- [ ] 输出文件位于约定路径，UTF-8 无 BOM
- [ ] 交付消息只给路径、统计、校验结果，未重复粘贴全文
- [ ] 长任务已删除 `deep-reading/_work/` 临时目录（或明确保留为工作文件）

## 4. 常见报错与修复

| 报错 | 修复动作 |
| --- | --- |
| `板块编号应为 [1, 2, 3]，实际 [1, 3]` | 重排该章板块编号，不影响内容顺序 |
| `未找到任何 ### 板块 N 标题` | 该章尚未按板块拆分，回到 Step 3 补拆与展开 |
| `本章总结与深度启示 应恰好出现 1 次` | 删除重复总结，或在缺失章节补写 |
| `缺少 ## 全书宏观总结与底层知识图谱` | 补齐 Step 4 收尾章节 |
| `出现占位符或截断话术` | 定位该行，补写实体内容，删除占位文字 |
| `出现交互模式残留` | 删除逐章交互话术（本技能不输出"回复继续"） |
| `存在【原文逻辑跳跃】标注，但缺少《附录 X｜忠实度与未补齐清单》` | 新建附录 B 并逐条汇总跳跃位置 |
| `以下原文章节在输出文档中缺失` | 回到缺失章节，完成拆解后追加写入 |
| `板块正文仅 42 字` | 该板块被压缩成结论，回到原文补机制展开 |
| `膨胀比 0.63 < 1.0` | 存在摘要化，优先复核高密度理论章节 |
